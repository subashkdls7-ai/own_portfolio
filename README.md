# own_portfolio

Personal portfolio website for **Hari Kandel** — hosted on GitHub Pages at [harikandel.com.np](https://harikandel.com.np).

## Sections

- Hero
- About Me
- Research & Publications
- Education
- Certificates & Achievements
- Projects & Activities
- Get in Touch

## Tech

Single-file static site — plain HTML, CSS, and JavaScript. No build step required.

## Local preview

Open `index.html` directly in a browser, or serve it locally:

```bash
python -m http.server 8000
```

## Deploy

The site is served from the `main` branch via GitHub Pages with a custom domain (see `CNAME`).
